# Exercício Prático: A Tabuada e o Mealheiro

Hoje o nosso programa aprendeu a repetir: usámos o `for` para contar, o `while` para repetir até alguma coisa acontecer e o `do...while` para perguntar até a resposta ser válida; depois, organizámos o código em funções com parâmetros e `return`. Agora é a vossa vez: vão criar uma tabuada e um mealheiro que calcula quantos dias faltam para a viagem ao Carnaval do Mindelo.

O vosso objetivo é escolher o ciclo certo para cada situação, evitar ciclos infinitos, e dividir o programa em funções pequenas, cada uma com uma tarefa e um nome que a explica.

Os ficheiros de partida estão na pasta [`ex-003/`](./ex-003/): as páginas `tabuada.html`, `mealheiro.html` e `bonus.html` já estão prontas e ligadas aos ficheiros da pasta `scripts/`, que só têm o título. Vocês escrevem o JavaScript.

### Missão 1: Sigam o Ciclo

1. Para cada ciclo abaixo, **escrevam num papel**, linha a linha, o que vai aparecer na Console. Depois confirmem, escrevendo-o na Console de uma página qualquer (usem **Shift + Enter** para mudar de linha sem correr o código):
   - `for (let i = 0; i < 3; i++) { console.log(i); }`
   - `for (let i = 10; i > 0; i -= 3) { console.log(i); }`
   - `let n = 1; while (n < 50) { n *= 3; } console.log(n);`
   - `for (let i = 1; i <= 6; i++) { if (i === 4) { break; } console.log(i); }`
   - `for (let i = 1; i <= 6; i++) { if (i % 3 === 0) { continue; } console.log(i); }`

_Seguir um ciclo volta a volta, no papel, é a melhor forma de perceber o que ele faz. Os programadores fazem isto quando um ciclo não dá o resultado esperado._

### Missão 2: A Tabuada

1. Na pasta `uf1.2-javascript`, criem a pasta `ex-003` e copiem para lá os ficheiros de partida [`tabuada.html`](./ex-003/tabuada.html) e [`scripts/tabuada.js`](./ex-003/scripts/tabuada.js) (o `tabuada.js` vai para a pasta `scripts`).
2. Criem a função `pedirNumeroDe1a10()`, que pergunta com `prompt` "Que tabuada querem ver? (1 a 10)" **até** a resposta ser um número inteiro de 1 a 10 (`do...while` e `Number.isInteger`), e o devolve. Se carregarem em Cancelar, devolve `0`.
3. Criem a função `mostrarTabuada(numero)`, que mostra a tabuada com um `for`: `7 x 1 = 7` até `7 x 10 = 70`.
4. Criem a função `somarTabuada(numero)`, que **devolve** (com `return`) a soma dos dez resultados. A soma da tabuada do 7 é 385.
5. Criem a função `mostrarResultadosPares(numero)`, que mostra só os resultados pares, usando `continue` para saltar os ímpares.
6. Usem as quatro funções: perguntem o número e, se não for `0`, mostrem a tabuada, a frase `A soma da tabuada do 7 é 385.` e os resultados pares.

_Dica: escrevam e testem uma função de cada vez. Comecem pela `mostrarTabuada(7)`, sem `prompt`, e só no fim juntem a pergunta._

### Missão 3: O Mealheiro para o Carnaval

Querem ir ao Carnaval do Mindelo e estão a poupar para a viagem. Todos os dias põem o mesmo valor no mealheiro e, a cada 7 dias, a avó junta mais 500 escudos.

1. Copiem para a pasta `ex-003` os ficheiros [`mealheiro.html`](./ex-003/mealheiro.html) e [`scripts/mealheiro.js`](./ex-003/scripts/mealheiro.js).
2. Criem a função `pedirNumeroPositivo(pergunta)`, que pergunta **até** a resposta ser um número maior do que 0 e o devolve (ou `0` se cancelarem). Usem-na para perguntar o preço da viagem e quanto conseguem poupar por dia.
3. Criem a função `diasParaPoupar(objetivo, porDia)`, que, com um `while`, junta o valor de cada dia até chegar ao objetivo, junta os 500 escudos da avó nos dias 7, 14, 21... (usem o `%`), mostra o total no fim de cada semana (`Semana 1: 2600 escudos`) e **devolve** o número de dias.
4. Criem a função `semanasEDias(dias)`, que devolve um texto como `3 semana(s) e 4 dia(s)` (dica: o resto da divisão por 7 são os dias que sobram).
5. Mostrem o resultado: com uma viagem de 9000 escudos e 300 por dia, devem ver as semanas 1 a 3 (2600, 5200 e 7800 escudos) e `Precisam de 25 dias: 3 semana(s) e 4 dia(s).`
6. Façam o ciclo do Git: `git add .`, `git commit -m "Ficha 3: tabuada e mealheiro"` e `git push`.

**Critérios de sucesso:**

- [ ] A pasta `ex-003` tem `tabuada.html`, `mealheiro.html`, `scripts/tabuada.js` e `scripts/mealheiro.js`.
- [ ] As perguntas repetem-se até a resposta ser válida, e Cancelar não cria um ciclo infinito.
- [ ] Todas as funções pedidas existem, com os nomes pedidos, e as que calculam usam `return`.
- [ ] A tabuada do 7 mostra 10 linhas, a soma 385 e os pares 14, 28, 42, 56 e 70.
- [ ] O mealheiro dá 25 dias para 9000 escudos a 300 por dia.
- [ ] Só `let` e `const`, e nenhuma variável usada fora do seu bloco.
- [ ] O repositório `uf1.2-javascript` no GitHub tem a pasta `ex-003`.
